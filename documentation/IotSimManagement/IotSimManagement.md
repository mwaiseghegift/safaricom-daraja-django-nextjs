<p>The IoT SIM Management APIs make it easy for developers and businesses to manage their Safaricom IoT SIM cards and messaging services. With these APIs, you can efficiently handle SIM lifecycle management, monitor in real-time, and send messages, ensuring your connected devices run smoothly.</p>
<p>These APIs help you automate SIM and messaging tasks, improve device connectivity, and boost communication efficiency in your IoT applications.</p>
<h4 id="key-features-of-the-apis-include">Key features of the APIs include:</h4>
<ul>
<li>
<p>SIM Operations:</p>
<ul>
<li>Activate, suspend &amp; rename SIM cards or assets</li>
<li>Retrieve all SIMs, check SIM lifecycle status, query customer &amp; product details</li>
<li>Analyze activation trends.</li>
</ul>
</li>
<li>
<p>Messaging:</p>
<ul>
<li>Send single or bulk messages</li>
<li>Search messages</li>
<li>Filter messages</li>
<li>Delete messages</li>
<li>Fetch all stored messages.</li>
</ul>
</li>
<li>
<p>Supports Automated Testing via the Simulator</p>
</li>
<li>
<p>Postman Collection</p>
</li>
</ul>
<h2 id="how-it-works">How It Works</h2>
<ol>
<li>A developer retrieves the Consumer Key and Consumer Secret from the Daraja Portal.</li>
<li>The developer sends a request to the Authorization API using Basic Authentication.</li>
<li>The API validates credentials and returns an access token.</li>
<li>The token is then used in subsequent API calls.</li>
</ol>
<h2 id="getting-started">Getting Started</h2>
<h3 id="prerequisites">Prerequisites</h3>
<ol>
<li>Create a Daraja Account on <a href="https://daraja.safaricom.co.ke/">Safaricom Developer Portal</a>.</li>
<li>Create an sandbox app in the portal to get API credentials.</li>
<li>Retrieve Consumer Key &amp; Consumer Secret from your sandbox app on  <a href="https://daraja.safaricom.co.ke/myapps">My Apps</a>.</li>
<li>Have access to the IoT platform. <a href="https://www.iotsimmanagement.safaricombusiness.co.ke/landing-page">Safaricom IoT SIM Management </a>.To get access to the platform, you will need to buy our IoT SIM Connectivity solution on <a href="https://www.business.safaricom.co.ke/products/IoTSimManagement">Safaricom Business Hub</a>. You will be assigned an active number that you will use here.</li>
<li>If actioning on behalf, the Admin's Username and account number <a href="https://www.iotsimmanagement.safaricombusiness.co.ke/landing-page">Safaricom IoT SIM Management </a></li>
</ol>
<h3 id="good-to-know">Good to Know</h3>
<p>The APIs are divided into two categories: the SIM operations APIs that allow users to manage their SIM cards and Messaging APIs that allow users to manage messages.</p>
