<p>The Reversals API enables the reversal of Customer-to-Business (C2B) transactions.</p>
<h2 id="how-it-works">How It Works</h2>
<ol>
<li>The organization sends a reversal request via the Daraja API Gateway.</li>
<li>The gateway authenticates and forwards the request to the M-PESA system.</li>
<li>M-PESA processes the reversal, refunds the customer, sends an SMS notification, and returns the result through Daraja to the organization.</li>
</ol>
<blockquote>
<p><strong>Note:</strong> This API is asynchronous and can be consumed over the internet, VPN, or Multiprotocol Switch.</p>
</blockquote>
<h2 id="getting-started">Getting Started</h2>
<h3 id="prerequisites">Prerequisites</h3>
<ul>
<li>Create a Daraja Account on the <a href="https://daraja.safaricom.co.ke/">Safaricom Developer Portal</a>.</li>
<li>Create a sandbox app to get API credentials.</li>
<li>Retrieve Consumer Key &amp; Consumer Secret from your sandbox app on <a href="https://daraja.safaricom.co.ke/dashboard/myapps">My Apps</a>.</li>
<li>Test data is available in the simulator section.</li>
<li>For production, ensure you have a live pay bill/till number with Business Admin/Manager operators created.</li>
</ul>
<h3 id="good-to-know">Good to Know</h3>
<p>This API is asynchronous. This API is used to check the status of a customer to business, business to business, Business to customer, Reversal and IMT transactions that happen on M-PESA.</p>
<h2 id="authentication">Authentication</h2>
<p>Devs gather here! You will first generate an access token to authenticate you to make the API call. See below generate access token <a href="https://daraja.safaricom.co.ke/dashboard/apis?api=Authorization">API</a> here. We’ve also automated this on the simulate request section.</p>

<h2 id="how-to">How To</h2>
<p><strong>Access to the M-PESA Organization Portal and create Users</strong></p>
<p>The M-PESA organization portal is a platform designed for businesses and organizations to manage their financial transactions through the M-PESA services.</p>
<p>The portal offers various features for businesses, including:</p>
<ol>
<li>Transaction Management: Monitor and manage transactions, generate reports, and reconcile accounts.</li>
<li>Account Management: Manage multiple user accounts with different access levels within the organization.</li>
<li>Bulk Payments: Facilitate bulk payments to employees, suppliers, and other beneficiaries efficiently.</li>
</ol>
<p><strong>Access to the M-PESA Organization Portal</strong></p>
<p><img src="/docs/images/org-portal.png" alt="org-portal!" title="org-portal"></p>
<p>To access the Organization portal (<a href="https://org.ke.m-pesa.com/orglogin.action">https://org.ke.m-pesa.com/orglogin.action</a>), you need to have a Business Administrator role created under your business short code (Pay Bill/ Till).</p>
<p>The first step before getting access, is to ensure the settlement option set to your short code is Bank via a Head Office application.</p>
<p>To make an application for a Head Office for your short code/Store Number kindly contact <a href="mailto:M-PESABusiness@Safaricom.co.ke">M-PESABusiness@Safaricom.co.ke</a> where they will provide you with the forms to be filled.</p>
<p>After Head Office is created the <a href="mailto:M-PESABusiness@Safaricom.co.ke">M-PESABusiness@Safaricom.co.ke</a> will also guide on the creation of the Business Administrator (username).</p>

<h2 id="how-to-login-to-m-pesa-organization-portal-for-the-first-time">How to login to M-PESA Organization Portal For the first time:</h2>
<ol>
<li>Launch the link from any of the browsers: <a href="https://org.ke.m-pesa.com">https://org.ke.m-pesa.com</a>.</li>
<li>Enter the Short code which is Bulk payment number.</li>
<li>Enter the Business Administrator username received on email.</li>

</ol>
<h2 id="account-types-in-c2b-organization">Account Types in C2B Organization</h2>
<ol>
<li>
<p><strong>MMF/WORKING/M-PESA ACCOUNT FOR ORGANIZATION</strong></p>
<ul>
<li>When an organization wants to make a business withdrawal, the funds are transferred to this account before the withdrawal request is made.</li>
</ul>
</li>
<li>
<p><strong>UTILITY ACCOUNT</strong></p>
<ul>
<li>Payments from customers are credited into the utility account.</li>
</ul>
</li>
<li>
<p><strong>CHARGES PAID ACCOUNT</strong></p>
<ul>
<li>For payments received from customers, depending on the tariff, a charge is levied on the Organization or is split between the organization and the customer. The charges paid account is debited and always accrues a negative balance which has to be settled before an organization can make a withdrawal request.</li>
</ul>
</li>
<li>
<p><strong>ORGANIZATION SETTLEMENT ACCOUNT</strong></p>
<ul>
<li>This account does the calculations for the organization operator when s/he initiates a revenue settlement. This account settles the charges paid account and then moves the balance from the Utility Account to the MMF account automatically. You will notice that the transaction type “Move funds from Utility to MMF” is no longer available as the revenue settlement process takes care of this.</li>
</ul>
</li>
</ol>

<h2 id="faqs">FAQs</h2>
<h3 id="why-am-i-not-receiving-callbacks-on-my-reversal-resulturl">Why am I not receiving callbacks on my Reversal ResultURL?</h3>
<ul>
<li>Ensure your callback endpoint is reachable over the internet and uses a public IP or domain.</li>
</ul>
<h3 id="what-should-i-do-if-i-encounter-an-invalid-access-token-error">What should I do if I encounter an invalid access token error?</h3>
<ul>
<li>Ensure the access token has not expired (expires hourly).</li>
<li>Use the correct consumer key and secret.</li>
</ul>
<h3 id="how-can-i-determine-if-the-reversal-request-was-successful">How can I determine if the Reversal request was successful?</h3>
<ul>
<li>The API is asynchronous. You receive an acknowledgement first, and the actual result is sent to your <code>ResultURL</code>. A successful reversal has <code>ResultCode</code> 0.</li>
</ul>
<h3 id="what-api-role-should-i-assign-to-my-api-user-for-reversal-requests">What API role should I assign to my API user for Reversal requests?</h3>
<ul>
<li>Assign the <strong>Org Reversals Initiator API</strong> role.</li>
</ul>
<h3 id="how-do-i-activate-a-pending-api-user">How do I activate a pending API user?</h3>
<ul>
<li>Set their password via the M-PESA portal as a user with the Set Restricted ORG API PASSWORD role.</li>
</ul>
<h3 id="why-am-i-receiving-an-initiator-information-is-invalid-error">Why am I receiving an ‘initiator information is invalid’ error?</h3>
<ul>
<li>Check API user credentials, username, and password encryption.</li>
</ul>
<h3 id="why-am-i-receiving-the-security-credential-is-locked-error">Why am I receiving ‘The security credential is locked’ error?</h3>
<ul>
<li>Multiple invalid credential attempts lock the password. Unlock via the Business Administrator.</li>
</ul>
<h3 id="what-should-i-do-to-resolve-an-invalid-api-call-as-no-apiproduct-match-found-error">What should I do to resolve an ‘Invalid API call as no apiproduct match found’ error?</h3>
<ul>
<li>Ensure the Reversal product is enabled on your Daraja application and you are using the correct endpoint.</li>
</ul>
<h3 id="can-i-reverse-a-b2c-transaction-using-the-reversal-api">Can I reverse a B2C transaction using the Reversal API?</h3>
<ul>
<li>No. B2C reversals are done manually on the M-PESA portal.</li>
</ul>
<h3 id="what-could-cause-bad-request---invalid-recieveridentifiertype-error">What could cause 'Bad Request - Invalid RecieverIdentifierType’ error?</h3>
<ul>
<li>Wrong Content-Type header, incorrect parameter name, or invalid/missing value.</li>
</ul>
<h3 id="api-reversal-failing-due-to-initiator-information-is-invalid">API reversal failing due to 'initiator information is invalid'?</h3>
<ul>
<li>Use the correct API user (access channel-API) and ensure the user is active.</li>
</ul>
<h3 id="what-is-the-process-of-creating-an-initiator">What is the process of creating an Initiator?</h3>
<ul>
<li>Create a Business Manager, then an API operator, and set the API user's password.</li>
</ul>
<h3 id="how-do-i-generate-security-credential">How do I generate Security Credential?</h3>
<ul>
<li>Encrypt the base64 encoded initiator password with M-Pesa’s public key certificate using RSA and PKCS #1.5 padding.</li>
</ul>
<h3 id="what-is-a-short-code">What is a short code?</h3>
<ul>
<li>Unique number allocated to a pay bill or buy goods organization for receiving payments.</li>
</ul>
<h3 id="how-will-i-log-in-to-the-m-pesa-portal">How will I log in to the M-PESA portal?</h3>
<ul>
<li>Use the provided link, shortcode, username, and password. Follow the prompts to set up your account.</li>
</ul>
<h3 id="what-should-i-do-when-the-business-administrator-role-is-dormant">What should I do when the Business Administrator role is Dormant?</h3>
