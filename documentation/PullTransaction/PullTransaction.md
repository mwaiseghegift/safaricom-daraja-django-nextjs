class="docs_tableContainer__qBw9Z MuiBox-root css-1oyv9ht"><h2 id="overview">Overview</h2>
<p>The Pull Transactions API is a reconciliation tool that lets partners query all C2B transactions performed under their Pay bill/Till number within the last 48 hours. It stores transaction data and helps recover any transactions that failed to reach the registered callback URLs during a specific period, providing a complete list of both successful and missed notifications.</p>
<h2 id="how-it-works">How It Works</h2>
<ol>
<li>The merchant is authenticated to register their Pay bill or Till number for pulling transactions via API</li>
<li>Due to system downtime, the merchant misses some callback notifications from M-PESA.</li>
<li>The merchant sends a GET request to retrieve all transactions for a specified period.</li>
<li>The merchant reconciles the transactions using the retrieved data.</li>
</ol>
<h2 id="getting-started">Getting Started</h2>
<h3 id="prerequisites">Prerequisites</h3>
<ul>
<li>Create a Daraja Account on Safaricom Developer Portal.</li>
<li>Create a sandbox app to get API credentials.</li>
<li>Retrieve Consumer Key &amp; Consumer Secret.</li>
<li>Use test data from the simulator section.</li>
<li>Live M-PESA pay bill/till number with Business Admin/Manager operators created with an existing C2B API intergration - For Go live</li>
</ul>
<h3 id="good-to-know">Good to Know</h3>
<ul>
<li>The API is asynchronous.</li>
<li>Method is POST for Register Pull and GET for Pull transaction</li>
<li>Can be consumed over the internet, VPN, or Multiprotocol Switch.</li>
</ul>

<ol>
<li><strong>MMF/Working/M-PESA Account</strong>: For business withdrawals.</li>
<li><strong>Utility Account</strong>: Receives customer payments.</li>
<li><strong>Charges Paid Account</strong>: Debited for transaction charges.</li>
<li><strong>Organization Settlement Account</strong>: Settles charges and moves balance.</li>
</ol>
<h2 id="portal-roles">Portal Roles</h2>
<h3 id="business-administrator">Business Administrator</h3>
<ul>
<li>Creates system users and assigns roles.</li>
<li>Cannot view transactions.</li>
<li>Created by Safaricom.</li>
</ul>
<h3 id="business-manager">Business Manager</h3>
<ul>
<li>Approves transactions, checks balances, views statements, withdraws funds.</li>
</ul>
<p><strong>Steps to Create Business Manager:</strong></p>
<ol>
<li>Log in as Business Administrator.</li>
<li>Select operators.</li>
<li>Click "Add".</li>
<li>Enter username, select access channel as Web.</li>
<li>Assign role, set password, submit KYC info.</li>
</ol>

<h3 id="api-user-creation">API User Creation</h3>
<p><strong>Steps:</strong></p>
<ol>
<li>Log in as Business Administrator.</li>
<li>Select operators.</li>
<li>Click "Add".</li>
<li>Enter API initiator username, select access channel as API.</li>
<li>Assign API roles, submit KYC info.</li>
</ol>
<p><img src="/docs/images/assign-api-role.png" alt="assign-api-role"></p>
<p><strong>Set API User Password:</strong></p>
<ol>
<li>Log in as Business Manager.</li>
<li>Go to Operator Management.</li>
<li>Search API user, click operations, set password.</li>
</ol>

<h2 id="faqs">FAQs</h2>
<h4 id="1-can-you-query-other-transactions-other-than-c2b">1. Can you query other transactions other than C2B.</h4>
<p>No: Currently Pull API only queries C2B transactions</p>
<h4 id="2-can-i-perform-pull-without-registering">2. Can I perform pull without registering</h4>
<p>No: You must register for the pull transaction API first</p>
<h4 id="3-how-long-are-transactions-available-for-pulling">3. How long are transactions available for pulling?</h4>
<p>Transactions can only be pulled within 48 hours</p>
<h4 id="4-purpose-of-offset">4. Purpose of offset</h4>
<p>Offset acts like the page number in pagination.</p>
<h4 id="5-invalid-access-token">5. Invalid access token</h4>
<pre><code> Error “Invalid Access Token”, occurs in case you are not using correct details combination of (Consumer key &amp; consumer secret)  
</code></pre>
<p>Also note, Access token expires after 1 hour, so you are required to regenerate.</p>
<h4 id="6-transaction-not-found-no-transaction-on-g2">6. Transaction not found /no transaction on G2</h4>
<p>This Means no transactions available at the selected time range.</p>
<h4 id="7-whats-nominated-number-how-can-i-get-it">7. Whats nominated number, how can I get it</h4>
<p>This is the number that was used during the Shortcode registration, it is found on the M-PESA portal under the Shortcode KYC details.</p></div></div></div></div></div>
