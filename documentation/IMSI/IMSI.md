class="docs_tableContainer__qBw9Z MuiBox-root css-1oyv9ht"><h2 id="overview">Overview</h2>
<p>IMSI in full means International Mobile Subscriber Identity. The IMSI API allows users to query the network age of a Safaricom phone number. The API acts as a security enhancement thus preventing fraud cases. Partners will be able to query phone number network registration date, hashed IMSI number and the last swap date.<br>
Partners will be able to get:</p>
<ul>
<li>Hashed IMSI</li>
<li>Age on Network &lt; 6 months</li>
<li>Swap Date &lt; 3 Months</li>
</ul>
<h2 id="onboarding">Onboarding</h2>
<p>To be onboarded partners can either write to <a href="mailto:apisupport@safaricom.co.ke">apisupport@safaricom.co.ke</a> or reach out to their account manager with the request to be onboarded to the SWAP API. The partner will have to make commercial agreements after which they will be onboarded to the sandbox and production environments.</p>

<h2 id="how-it-works">How It Works</h2>
<ul>
<li>Organization sends an API request to Daraja with the customer's phone number</li>
<li>Daraja authenticates the API call and forwards the request to M-PESA</li>
<li>M-PESA returns the hashed IMSI, Age on network and last swap date to Daraja which forwards the response to organization system</li>
</ul>
